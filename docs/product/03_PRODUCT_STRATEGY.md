# PRODUCT STRATEGY

## Product vision

Construir una experiencia digital de grading donde el coleccionista entienda, confíe y pueda seguir todo el proceso de su carta.

## Core product journey

1. Discover
2. Learn
3. Pre-check / estimate
4. Submit
5. Ship or drop-off
6. Receive
7. Authenticate / inspect
8. Grade
9. Encapsulate
10. Certify
11. Track
12. Verify
13. Collect / share

## MVP web

### Public
- Home
- Services
- How it works
- Pricing
- Card verification
- FAQ
- Contact / events

### Transactional
- Submission wizard
- User account
- Order summary
- Payment placeholder/integration point
- Tracking

### Certification
- Certificate page
- Grade breakdown
- Card images
- QR verification

## Next layer

- Collection dashboard
- Population report
- Digital reports
- Pre-grading
- B2B dashboard
- Event mode

## Product principle

El MVP debe demostrar confianza y claridad antes de intentar demostrar una IA espectacular.
