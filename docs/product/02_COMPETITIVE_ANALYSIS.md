# COMPETITIVE ANALYSIS

## Objetivo

No copiar interfaces. Estudiar qué promete cada player, qué experiencia construye y qué ideas podrían ser relevantes para Gorilla.

## Players a estudiar

### PSA
Aprendizaje: reconocimiento de marca, ecosistema, certificación, population data y experiencia de investigación.

### CGC
Aprendizaje: variedad de categorías, certificación, tracking y ecosistema de coleccionismo.

### Beckett / BGS
Aprendizaje: identidad premium, subgrades y fuerte lenguaje visual alrededor de la calidad.

### TAG
Aprendizaje: convertir el análisis y la evidencia del grading en un producto digital.

### Arena Club
Aprendizaje: combinar grading, IA, colección, marketplace y experiencia digital.

### GRAAD
Aprendizaje: comunicar análisis óptico/digital como parte de la propuesta.

### AP / PGS / PCA / AGM / William Turner / EGS
Aprendizaje: competir por segmentos de precio, velocidad, estética, proximidad o comunidad.

## Cómo usar esta matriz

No convertirla en “quién gana”. Usarla para detectar:

- expectativas mínimas del mercado;
- features comoditizadas;
- features diferenciadoras;
- features que requieren capacidad operativa antes de prometerlas.
