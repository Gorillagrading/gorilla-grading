# UX/UI SYSTEM

## Core principle

Professional + modern + premium + approachable.

## Visual hierarchy

1. Carta / producto
2. Resultado / acción
3. Evidencia
4. Información secundaria

## Navigation

- Services
- How it works
- Pricing
- Verify
- Track
- Events
- Account

## Key pages

### Home
Hero + card visual + proposition + CTA + proof + process + technology + social/community + CTA.

### Services
Comparación simple de tiers.

### How it works
Visual storytelling from raw card to slab.

### Verify
Número/QR + resultado verificable.

### Grade result
Large score + breakdown + images + evidence + certificate.

### Submission
Wizard progresivo, lenguaje humano y resumen fijo.

### Account
Orders + collection + certificate history.

## Interaction rules

- Animations communicate state or physical process.
- Motion should be subtle and premium.
- Avoid long transitions that slow down the workflow.
- Every action needs feedback.

## Responsive

Desktop, tablet and mobile from the beginning.

## Accessibility

Keyboard navigation, visible focus, contrast, semantic HTML, labels, reduced-motion support.
