# AI STRATEGY

## AI should solve real problems

Priority candidates:

1. Card identification
2. Image quality checks
3. Pre-grading assistance
4. Defect detection support
5. Report generation
6. Customer support
7. Internal operations assistant

## LLM role

Use an LLM primarily for language, explanation, orchestration and document/report generation.

Do not make an LLM the sole authority for numerical grading.

## Grounding

Any customer-facing factual response about pricing, order status, availability or certificate data must come from authoritative system data.

## Human-in-the-loop

Official grading should have a clearly defined human QA path until the CV system has been validated with adequate data.

## Prototype

For the web prototype, AI can be simulated with deterministic mock results to demonstrate the UX without pretending that a production model already exists.
