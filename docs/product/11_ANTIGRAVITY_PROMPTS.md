# ANTIGRAVITY + GEMINI PROMPTS

## PROMPT 0 — PROJECT INITIALIZATION

You are building Gorilla Grading from scratch.

There is NO existing repository, no legacy codebase and no implementation to preserve.

The project is at concept/prototype stage.

Read all Markdown files in this project before coding.
Treat the provided CEO mockup as visual inspiration, not as existing product architecture.
Treat the Marketing research as source material and distinguish facts, internal research and hypotheses.

Do not build the entire production platform yet.

Your first objective is to create polished, independent website prototypes that allow the CEO to compare different product/design directions.

Use real-looking mock data where necessary, but label simulated functionality internally in code and documentation.

Before implementation:
1. Read the documentation.
2. Summarize the product principles.
3. Propose a prototype structure.
4. Create the base design system.
5. Then implement Model 01, Model 02 and Model 03 as independent routes/themes.

Do not overwrite one model with another.

## PROMPT 1 — MODEL 01: PRECISION LAB

Create a premium Gorilla Grading website prototype called “Precision Lab”.

Requirements:
- Gorilla branding.
- Green/black/off-white palette from provided visual system.
- Very clean layout.
- Strong editorial typography.
- Minimal but impressive motion.
- The card is always the visual protagonist.
- No gaming aesthetic.
- No excessive gradients.
- No visual clutter.

Pages:
/
/services
/how-it-works
/verify
/certificates/demo
/submit
/account

Hero concept:
A premium card is shown large with a subtle scanning/measurement layer.
Explain the promise without using technical jargon.

Create a section showing:
Raw card → Scan → Analysis → Grade → Certification.

Create an interactive grading demo using mocked data:
Centering, Corners, Edges, Surface and Final Grade.

The demo must make the technology understandable rather than merely decorative.

## PROMPT 7 — DO NOT OVERBUILD

Do not implement production payment processing, real shipping labels, real AI grading, or real Computer Vision in the concept stage.

Use interfaces and mock services.
Create clean boundaries so those systems can later be integrated without redesigning the UI.
